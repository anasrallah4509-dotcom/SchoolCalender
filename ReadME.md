Questo programma mostra le vacanze scolastiche per la scuola I.I.S "G. Vallauri" di Fossano.
Il programma usa la funzione DateTime per calcolare le date delle vacanze scolastiche in base al calendario scolastico italiano. Le vacanze includono Natale, Pasqua, Carnevale e le vacanze estive. 
L'utente può visualizzare le date delle vacanze per l'anno corrente o per un anno specifico inserendo l'anno desiderato.
